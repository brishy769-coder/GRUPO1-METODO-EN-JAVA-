## 📚 ⚡ Sobre esta práctica

> *"Pick a card, any card... pero asegúrate de que compile, mon ami."* — **Remy LeBeau**

Este repositorio reúne los ejercicios de la **APE: Práctica Evaluativa — Clase Producto y Competencia Final**.

Cada ejercicio está presentado en un PDF independiente con su **enunciado y solución en Java**. Los códigos incluyen un método `main` para probar su funcionamiento de golpe en la mesa.

---

## 🎯 Objetivo

Fortalecer los fundamentos de programación orientada a objetos mediante ejercicios de métodos, parámetros, tipos de retorno, validaciones e instanciación con el estilo y la potencia de una explosión kinética.

## 🧩 🂠 Ejercicios

| N.º | Ejercicio | ¿Qué se practica? |
| :---: | --- | --- |
| 01 | 📐 Tipos de retorno | Corregir un método que calcula el área y devolver el resultado con `double` y `return`. |
| 02 | 👋 Bienvenida | Crear un método `void` que reciba un nombre y una edad e imprima un saludo con clase. |

## 🛠️ Conceptos aplicados

<p align="center">
  <img src="https://media.giphy.com/media/3o7TKL3mB6yL37B63E/giphy.gif" alt="Gambito Kinetic Power" width="300">
</p>

- **Clases y objetos:** definir una estructura (el mazo) y crear instancias reales con `new`.
- **Atributos:** almacenar información y el estado de un objeto en mesa.
- **Métodos:** organizar acciones, trucos y cálculos lógicos.
- **Parámetros y argumentos:** recibir y enviar información con precisión de francotirador.
- **`void`:** declarar métodos que ejecutan una acción espectacular pero no devuelven un valor.
- **`return`:** finalizar un método y entregar la carta con el resultado correspondiente.
- **Tipos de datos:** trabajar sin fallos con `String`, `int`, `double` y `boolean`.
- **Condicionales:** comprobar si los datos cumplen las reglas de la jugada.
- **Paso por valor:** entender que un parámetro recibe una copia exacta del valor enviado.

## 💻 Cómo probar los códigos

1. Abre el PDF del ejercicio que deseas practicar.
2. Crea un proyecto Java en tu entorno de desarrollo.
3. Crea el archivo con el mismo nombre de la clase pública. Por ejemplo: `Bienvenida.java`.
4. Copia el código de la sección **Código Java · Solución**.
5. Ejecuta el método `main` y revisa el resultado en la consola.
6. Cambia los valores de prueba para observar cómo responde el programa.

> **⚠️ Importante (Remy's Warning):** prueba cada ejercicio por separado. Algunos utilizan nombres de clase repetidos, como `Calculadora` y `Producto`.
